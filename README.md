\# BookAI



BookAI is an Android application that lets users upload books and have AI-powered conversations about their content.



\## Project Structure



```text

BookAI/

├── Android/    # Android application

├── Backend/    # Node.js + Express + TypeScript backend

└── README.md

```



\## Tech Stack



\### Android



\* Kotlin

\* Jetpack Compose

\* MVVM

\* Hilt

\* Retrofit

\* Coroutines / Flow

\* Firebase Authentication



\### Backend



\* Node.js

\* Express

\* TypeScript

\* MongoDB

\* Redis

\* BullMQ



\### AI



\* Embeddings

\* Vector Search

\* RAG

\* Gemini



\### Future



\* Vapi for voice conversations
